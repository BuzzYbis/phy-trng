Observed events

ORDERED
    Linearization matters. “No commit after closure” refers to release-local t_close. It does not mean that detection at health instantly revokes a remote domain. G5/G6 must bound detection, propagation, in-flight commits and outstanding bytes.
    ICA · INPUT CREDIT

    Health → conditioner. Binds source/configuration, boot session, epoch, unique ID, immutable snapshot range and length, rounded-down entropy credit and expiry. The receiver owns its consumed-ID and range ledger.

    ORA · OUTPUT RELEASE

    Health → release, directly. Binds boot session, epoch, unique ID, boundary, request/generation/reseed provenance, output range, maximum bytes and deadline. A separate receiver ledger prevents replay and overlap.

    Conservative commit: copy staging into release-owned memory; revalidate current authority and bounds; consume the permit before the bounded commit. An interruption burns the reserved range. A partial error invalidates the caller’s whole request; it cannot revoke bytes already committed.

    Make authority visible.

    The seven application domains divide access to raw data, generator state and client commits. The timer, fault route, boot configuration and scheduling support are also part of the trusted system.

    Immutable handoffs

    Acquisition → health-private snapshot → test exact bytes → immutable accepted handoff. Then generator staging → release-private commit buffer → validate and publish.

    Memory rights are part of the argument. An authenticated tag over a mutable shared buffer is insufficient if the consumer can see different bytes. Prove every copy and mapping transition.

    DMA qualification

    Protected profile: an independent IOMMU/SMMU policy confines device writes; the driver cannot broaden it.

    Trust profile A-DMA-1: where such protection is absent, device/driver behavior is a system assumption. CPU address-space isolation alone does not confine DMA.

    Zero-event campaign

    ONE-SIDED 95%

    For independent Bernoulli trials with zero failures, the exact upper failure-probability bound is 1 − 0.05^(1/n). For all successes, the lower success bound is 0.05^(1/n).

    Declared confidence scope. Each bound is for one campaign. Testing many conditions does not automatically give the same simultaneous coverage. Use a predeclared family-wise method when that claim is needed. Overlapping windows are not automatically independent trials.

    Duration is ideal elapsed collection time, excluding warm-up, resets, analysis and downtime. A zero-event-only rule has low power near the acceptance boundary; specify any allowed-event rule and sample size before testing.
